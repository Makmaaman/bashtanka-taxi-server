# Bashtanka Taxi MVP (Local Uklon)

Мінімально життєздатний прототип сервісу таксі для невеликого міста:
- **PWA фронтенд** (React + Vite): ролі пасажир / водій / адмін в одному застосунку за різними маршрутами.
- **Сервер** (Node.js + Express + Socket.IO + SQLite): замовлення, водії, довідники, прості тарифи.
- **Мапа** (MapLibre + OSM-тайли), **Plus Codes** (Open Location Code), вибір «точок посадки».
- Проста формула ціни за км/хв з мінімалкою (налаштовується).
- Навігація для водія: deep-link у Google/Apple/Here/Organic Maps.
- Авторизація — спрощена (мок), зберігається в localStorage. SMS-провайдера можна додати згодом.
- Оплати: зараз «готівка/переказ», на 2-й ітерації підключимо monobank acquiring.

> ✳️ Центр карти бере **геолокацію користувача**. Якщо геолокація заборонена, є запасний центр (координати Миколаївської області).

## Швидкий старт

### 1) Сервер
```bash
cd server
cp .env.example .env
npm install
npm run dev
```
Сервер за замовчуванням: `http://localhost:4000`

### 2) Веб
```bash
cd web
cp .env.example .env
npm install
npm run dev
```
Фронтенд за замовчуванням: `http://localhost:5173`

### Ролі
- Пасажир: `http://localhost:5173/#/passenger`
- Водій: `http://localhost:5173/#/driver`
- Адмін: `http://localhost:5173/#/admin`

## Налаштування тарифів
Файл **server/src/pricing.js**. За замовчуванням:
- `base` (подача), `perKm`, `perMin`, `minPrice` для класів `eco`, `comfort`, `van`.
- Нічний коефіцієнт, коефіцієнт дощу/снігу — приклад, можна вимкнути.

## Довідник «точок посадки»
- Стартовий список у БД (SQLite) створюється при першому старті.
- Редагування — у вкладці **Admin → Landmarks**.
- Ви можете масово імпортувати CSV/JSON через кнопку Import у адмінці.

## Дані та БД
- SQLite-файл зберігається у `server/data.sqlite`. Створиться автоматично.
- Для продакшну рекомендовано PostgreSQL (PostGIS), але для MVP SQLite достатньо.

## Безпека
- Авторизація спрощена для демо.
- Обов'язково додайте справжній SMS-провайдер, логування та ролі перед реальним запуском.

## Ліцензії/Мапи
- MapLibre GL з OSM тайлами (`https://tile.openstreetmap.org/{z}/{x}/{y}.png`).
- Дотримуйтесь політики використання тайлів OSM; для продакшну краще підняти власний тайл-сервер/MapTiler.
